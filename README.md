# Udemy Courses Analytics | SQL, Python & Power BI

## Project Overview
This project focuses on analyzing Udemy course data to understand course distribution, pricing, popularity, and subscriber engagement. SQL, Python, and data visualization techniques are used to explore the dataset and identify meaningful trends.

## Dashboard Preview

![Udemy Courses Analytics Dashboard](<Udemy Courses Analytics Dashboard.png>)

## Dataset Information
- **Total Records:** 3,678
- **Total Columns:** 12
- **Unique Course IDs:** 3,672
- **Missing Values:** 0

## Tools & Technologies
- **SQL / MySQL** — Data querying and analysis
- **Python** — Data analysis and exploratory data analysis (EDA)
- **Pandas** — Data cleaning and manipulation
- **Jupyter Notebook** — Interactive Python analysis
- **Power BI** — Dashboard visualization

## Key Analysis Areas
- Paid vs. free course analysis
- Course distribution by subject
- Course levels and pricing
- Subscriber and review analysis
- Course publishing trends
- Popular courses based on subscriber counts
- Course duration and subscriber patterns

## Key Findings
- The dataset contains 3,678 course records and 12 columns.
- There are 3,672 unique course IDs.
- No missing values were found in the dataset.
- Paid courses account for the majority of course records.
- Subject and level comparisons help explain the composition of the course catalog.
- Subscriber and review counts provide indicators of recorded course engagement.

## Repository Files
- `udemy.csv` — Dataset used for the project
- `Udemy_Courses_SQL_Analysis.sql` — SQL queries for analysis
- `Udemy_Courses_Analysis.ipynb` — Python analysis using Jupyter Notebook
- `Udemy Courses Analytics Dashboard.png` — Dashboard preview

## Project Objective
The objective of this project is to apply practical data analysis skills to an online course marketplace dataset, explore business-related questions, and present findings in a clear and understandable format.
